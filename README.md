# RMT Portfolio Optimization Research

## Overview

This project applies Random Matrix Theory (RMT) to financial portfolio optimization.

The main objective is to denoise stock-return correlation matrices using RMT and then use the cleaned correlations for portfolio construction.

## Methods

- Random Matrix Theory (RMT)
- Correlation matrix denoising
- Eigenvalue spectrum analysis
- Markowitz Portfolio Optimization
- Hierarchical Risk Parity (HRP)
